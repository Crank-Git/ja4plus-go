# The generator of the documentation site. FR-documentation-8 states that one file pins
# every version, and this is that file.
#
# Install it into a fresh environment, and build the site with `make docs`.
#
#   python3 -m venv .venv
#   .venv/bin/pip install -r docs/requirements.txt
#   make docs
#
# Every line pins one exact version with `==`, and the list holds every transitive
# dependency. A range would let a generator release change the rendered site without a
# commit of this repository. A bump is a commit that does nothing else.
#
# The list was measured on 2026-08-14 with `pip freeze` in a fresh virtual environment on
# CPython 3.14.3, after `pip install mkdocs-material`. `pip` itself is absent from the
# list, because the environment supplies it.
#
# Two pins deserve a note.
#
#   - `mkdocs==1.6.1`. The Material team states that MkDocs 2.0 removes the plugin system
#     and the theming system, and that no migration path exists. So the major version is
#     a decision this project makes deliberately, and never one a resolver makes.
#   - `pymdown-extensions==11.0.1`. `mkdocs.yml` reads `pymdownx.slugs.slugify` from it to
#     match the GitHub heading slug, under FR-documentation-10.
