JA4LS — server latency and distance

JA4LS measures the server side of a connection. JA4LFingerprinter writes it, and the same fingerprinter writes JA4L for the client side.

4021_53_quic
PartMeaning
aThe measured time divided by the propagation factor for the hop count.
bThe hop count: the initial time-to-live minus the observed time-to-live.
cThe protocol marker. Present on a QUIC connection only, and its value is quic.

No FoxIO image specifies JA4LS. JA4L.png states no server rule, so every rule on this page cites a FoxIO implementation. docs/specs/foxio/JA4L.md names the sources.

The API reference is hand-written, and that is the one deliberate difference from the port. The port generates its reference from docstrings with mkdocstrings. Go already publishes a generated surface at pkg.go.dev, built from the same doc comments. A second generated copy would drift, so these pages explain the contract and link out for the signatures.
